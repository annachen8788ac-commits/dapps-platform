# DApps Platform — U.S. Website

Static website for the DApps Platform U.S. operating presence in development in Los Angeles, California.

## Important content policy
The site distinguishes DApps Platform USA from other DApps Platform-named legal entities appearing in public Trust Wallet records. Trust Wallet ecosystem facts are linked to primary sources and are not presented as proof that all entities are legally identical.

## Deployment
Upload the contents of this folder to the root of the GitHub repository and publish the `main` branch from `/ (root)` with GitHub Pages.
